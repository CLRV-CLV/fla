# Browser-side third-party libraries

These libraries are loaded locally by FLA; keep their accompanying license files when updating them.

- `interactjs/interact.min.js` — interact.js 1.10.28, MIT. Used for dragging/resizing classroom widgets.
- `xlsx/xlsx.full.min.js` — SheetJS Community Edition 0.20.3, Apache-2.0. Used to parse class rosters locally in the browser; roster files are not uploaded.
- `canvas-confetti/confetti.browser.js` — canvas-confetti 1.9.3, ISC. Loaded on demand for the random-picker celebration effect.
