# FLA 宝塔面板部署（不用 Docker）

分工：**宝塔 Python 项目**负责运行 FLA（创建虚拟环境、安装依赖、守护进程）；**宝塔 Nginx** 负责网站、SSL 和防火墙。系统软件（LibreOffice、ffmpeg、字体）宝塔装不了，需要用一条命令安装。

## 1. 宝塔软件商店

- 安装 **Nginx** 和 **Python项目管理器**（新版宝塔在 网站 → Python项目）。

## 2. 下载代码、安装系统依赖（宝塔 →「终端」）

```bash
mkdir -p /www/wwwroot/fla && cd /www/wwwroot/fla
curl -fL https://codeload.github.com/CLRV-FYX/fla/tar.gz/refs/heads/arena/d90b37ee-fla | tar -xz --strip-components=1
bash bt.sh deps
```

`deps` 只用 apt 安装 LibreOffice、ffmpeg 和中文字体，并放行 1935 端口。它不会创建任何服务，也不会改动宝塔的配置。

## 2b. 宝塔 → 网站 → Python项目 → 添加项目

| 选项 | 填写 |
|---|---|
| 项目路径 | `/www/wwwroot/fla` |
| Python 版本 | 3.11（没有的话先点「版本管理」安装） |
| 框架 | 其他 / 自定义（没有就选 FastAPI 或 Python） |
| 启动方式 | 命令行启动 |
| 启动命令 | `uvicorn server.main:app --host 0.0.0.0 --port 8306 --workers 1 --proxy-headers --forwarded-allow-ips 127.0.0.1` |
| 端口 | 8306 |
| 安装依赖 | 勾选，使用 `requirements.txt` |
| 开机启动 | 勾选 |

注意：

- `--workers 1` 必须保留。手机投屏的会话保存在内存里，开多个进程会连不上。
- 数据默认保存在 `/www/wwwroot/fla/data`（数据库、上传的文件、初始管理员密码 `initial_admin_password.txt`）。

如果要设置固定的管理员密码，在项目「环境变量」里加 `ADMIN_PASSWORD=你的密码`。这只在第一次启动、还没有管理员账号时生效。

启动后在终端执行 `curl -s http://127.0.0.1:8306/api/version`，能看到版本号就说明运行成功。

## 3. 宝塔添加网站（反向代理）

1. 宝塔 → 网站 → **添加站点**：域名填 `t.clrv.top` 和 `t.fyx.best`（一行一个），PHP 版本选「纯静态」。
2. 进入站点 → **配置文件**，把 `server { ... }` 里自带的 `location` 段全部删掉，换成下面这段，然后保存：

```nginx
    client_max_body_size 2048m;
    proxy_read_timeout 600s;
    proxy_send_timeout 600s;

    location / {
        proxy_pass http://127.0.0.1:8306;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_buffering off;
        proxy_request_buffering off;
    }
```

3. 站点 → **SSL** → Let's Encrypt，申请证书并打开「强制 HTTPS」。
4. **任意域名都能访问**：宝塔 → 网站 → 顶部 **默认站点** → 选中这个站点。之后用 IP 或者其它解析过来的域名访问，也会进入 FLA。

## 4. 防火墙

- 宝塔 → **安全**：放行 `80`、`443`、`1935`（iPhone 整屏投屏）。8306 只在本机内部使用，不用对外放行。
- **云服务器控制台的安全组**也要放行 TCP `80`、`443`、`1935`。

## 5. 更新

```bash
cd /www/wwwroot/fla && bash bt.sh pull
```

默认拉取分支 **arena/63f6f4b2-fla**（可在 `bt.sh` 顶部的 `BRANCH_DEFAULT` 改，或临时用
`bash bt.sh pull main` / `FLA_BRANCH=main bash bt.sh pull` 指定其他分支）。

这条命令只更新代码。然后到 宝塔 → Python项目 → FLA 点 **重启**。如果更新说明里提到依赖有变化，先在「模块」里重新安装 `requirements.txt`，再重启。
（装了 systemd 服务 `fla.service` 的部署，`bt.sh pull` 会自己重启并做健康检查，不用去宝塔点。）

网页底部会显示 `FLA v版本 · 更新时间`，用来确认更新是否成功。

## 6. 从旧服务器迁移数据（可选）

旧服务器的数据在 Docker 卷里：

```bash
docker run --rm -v deploy_fla-data:/d -v /root:/o alpine tar -czf /o/fla-data.tgz -C /d .
```

把 `fla-data.tgz` 传到新服务器，然后：

```bash
# 先在宝塔 Python项目里停止 FLA
cd /www/wwwroot/fla && mkdir -p data && tar -xzf /root/fla-data.tgz -C data
# 再在宝塔里启动
```

卷名不一定是 `deploy_fla-data`，可以用 `docker volume ls | grep fla` 查看。
